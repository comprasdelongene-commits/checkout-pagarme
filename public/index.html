Modo teste (homologação)

Use apenas chaves de TESTE (pk_test_ / sk_test_). A chave secreta é enviada só nesta requisição, não é gravada no servidor e serve apenas para homologação. Deixe os dois campos em branco para usar o fluxo de produção.

Cartões de teste oficiais da Pagar.me

Fonte: Simulador de Cartão de Crédito. Use validade futura (ex.: 12/29) e um CVV qualquer (ex.: 123).

  • 4000 0000 0000 0010 Sucesso — qualquer operação é aprovada (capturado/pago)
  • 4000 0000 0000 0028 Falha — transação não autorizada
  • 4000 0000 0000 0036 Processing → Sucesso — começa pendente e depois é pago
  • 4000 0000 0000 0044 Processing → Falha — começa pendente e depois falha
  • 4000 0000 0000 0077 Sucesso → Processing → Sucesso — no cancelamento, termina estornado
  • 4000 0000 0000 0093 Sucesso → Processing → volta ao sucesso da 1ª operação
  • 4000 0000 0000 0051 Processing → Cancelado — termina estornado
  • 4000 0000 0000 0069 Pago → Chargeback — depois muda para chargedback

Qualquer outro número retorna “não autorizada”. Se a sua conta for PSP, confira também as regras de CVV/documento no Simulador PSP.
